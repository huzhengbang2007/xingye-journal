# 星野记 2.4 · 独立 Android App

本版已经替换 2.0 的远程页面入口。**安装包自带全部页面与本机加密数据层，先进入自己的 App，需要时才连接电脑同步。** 无需电脑在线，也不需要先输入服务器地址。

## 安装后先做什么

1. 将本次构建生成的 `xingyeji-2.5.0-debug.apk` 传到手机或 Pad 7，通过系统安装界面安装。相同签名的测试版可覆盖升级；不要主动清除应用数据。
2. 首次打开直接显示本机欢迎页面，创建至少 10 字符的**本机主密码**。它可以与电脑保险库密码不同。
3. 日程、课表、CSV / XLSX 账单导入、本地空闲时段规划与月度统计可以离线使用。手记另设独立密码，仍在浏览器引擎内部二次加密。
4. 如果要调用 AI，在这台设备的设置中填写自己的 DeepSeek 密钥。本机原生端直接访问固定官方 HTTPS 接口，不需要电脑代转；仍需逐次确认发送范围，调用需要互联网与账户额度。
5. 及时导出加密备份。清除应用数据、卸载或遗失本机密码会导致本机记录不可用；旧 2.0 的电脑记录仍在电脑，连接后可以合并过来。

这是纯 Java 原生安装包与随包发布的网页界面，不是打开电脑网页的快捷方式。Android WebView 负责显示随包资源与执行 Web Crypto；日历、闹钟、HTTPS 同步与系统文件选择由受限原生桥接处理。**尚未在你的小米实机上安装验证。**

## 存储与密码

- 本机记录存放于 Android 应用私有的 WebView IndexedDB，持久化的整库是 AES-256-GCM 密文，主密码通过 PBKDF2-SHA256 310000 次派生。主密码与解密密钥不写入持久化设置。
- 独立日记在整库之内再次加密，包含日期、标题、心情和正文。离开页面或 5 分钟无操作后二次锁定，未保存输入会清除。
- 本机主密码、日记密码和电脑主密码不经过配对网络接口。扫码绑定电脑身份，电脑确认后发放可撤销的设备凭证；凭证通过 Android Keystore 加密保存，不交给网页或写入日志。
- 手机导出 v2 加密备份可在本版电脑上恢复；电脑旧版 v1 备份需要先在电脑恢复再同步到手机。手机导出与原生传输目前各有 16 MB 内容限制，超大历史数据请先在电脑整理。
- 系统备份与设备迁移已排除应用数据，不自动云备份。FLAG_SECURE 用于限制截图和最近任务预览；这不替代加密，也不防恶意输入法或被攻破的系统。

## 需要时再同步

电脑打开并解锁星野记，点击「连接设备」显示二维码。手机或平板解锁后点击顶部「连接设备」扫码，再由电脑点击「允许配对」。相机权限只在扫码时申请。

配对完成后，前台打开并解锁、网络可达时自动同步；保存后短延迟检查，其他设备变更通常在下一次检查时合并。点击顶部状态可立即同步。电脑关闭或锁定时暂停同步，本机仍可离线记录。无需输入电脑密码、手填地址或安装系统证书；地址变化会尝试发现电脑，发现受限时重新扫码。

电脑和本机需网络互通；校园网不通时让电脑连接自己的手机热点，允许 Windows 防火墙专用网络访问。设置中可以重新扫码或解除配对，电脑可以命名与撤销设备。

无冲突自动合并，同一记录同时修改时选择版本；日记交换整本二次加密密文，不能自动合并正文。AI 密钥和两端设置各自保留。同步先保留加密回滚副本，写入失败不显示成功。正在编辑时暂缓刷新；锁屏后台持续同步不作承诺。

2.4 按当前设计关闭双指缩放和字号调节，保留浅色、深色、跟随系统选项。原生层将状态栏、导航栏与屏幕挖孔安全区传给页面，旋转后重新计算；页面控制内容留白，不重复叠加原生 padding。状态栏文字和导航图标跟随当前页面主题调整。该适配仍需在具体 HyperOS 版本、横屏和三键导航下实机复核。

## 系统日历和闹钟

本机日程可以独立同步到系统日历，不需要先同步电脑。进入设置，开启「此设备自动同步到系统日历」，按系统提示授予日历读取 / 写入权限。只创建和修改专用「星野记」本地日历中的本应用事件；不要把手记或账单写入日历。

- 单向同步：App → 系统日历，系统日历中的修改不会反写 App。相同快照去重，删除和修改会随本机保存更新。
- 进入系统日历后的日程是**普通明文记录**，其他获得日历权限的应用可能读取，日历账户也可能同步。独立日记不走此通道。
- 关闭自动同步不会删除已写入事件，卸载也不保证删除专用日历，请按需在系统日历清理。
- 系统日历提醒的实际触发受 HyperOS 权限与省电策略影响，未实机验证。
- 设置中可直接打开系统日历、本应用权限页和系统省电设置；检查系统日历中「星野记」日历的显示开关，并按需添加小米系统日历小组件。入口只使用 Android 标准 Intent，没有调用小米私有协议，也不会自动授予后台权限。
- 保存日程勾选系统闹钟时，使用标准 `AlarmClock.ACTION_SET_ALARM`，仅支持未来 24 小时内且能对应下一次时钟时分的单次安排。打开系统时钟确认页，不宣称已经保存。
- 修改或删除日程不自动删除旧系统闹钟，需在系统时钟核对；远期安排使用日历提醒。

## 原生权限与构建

固定本地页面来源为 `https://appassets.androidplatform.net`，资源全部从 APK 内部读取，不从互联网加载该域名。只向这个本地顶层页面授予消息端口，不使用 `addJavascriptInterface`。网络请求仅支持配对的私有局域网电脑与固定 DeepSeek 官方接口，不开放任意 Intent 或文件系统读取接口。文件导出使用系统文档保存器，由用户选择保存位置。

同步连接仅信任扫码绑定的电脑指纹，身份变化会拒绝连接；该校验不修改全局 TLS 设置。普通网络请求只信任系统证书。测试包是个人侧载候选版本，实机验收后再考虑正式发行。

使用已存在的 JDK 21、Gradle 9.1.0、AGP 8.13.0、SDK 36 编译。构建任务自动把根目录 `public` 资源打进 APK，不包含 `data`、`certs` 或任何用户保险库。

```powershell
pwsh -File ..\scripts\build-android.ps1 -Sdk '你的SDK目录' -Jdk '你的JDK目录' -Gradle '你的gradle.bat路径'
```
