星野记隐私说明

更新日期：2026-10-24。适用版本：3.0.0-rc。开发者标识：HOSHINO TEAM。支持入口。隐私声明公开网页。

本地记录

日程、课程、账本及设置保存在用户设备的加密保险库中。日记使用独立密码进行二次加密。主密码无法找回，请自行保存密码及加密备份。CSV、Markdown 等明文导出文件由用户自行保管。

可选 AI

未配置 API Key 时，本地记录、导入、统计与备份仍可使用。启用 DeepSeek 后，每次云端调用都需要明确确认，并使用用户自己的服务额度。

AI 规划发送本次目标、作息、规划范围、时长及已有日程的日期和起止时间，不发送已有日程标题和地点。月度复盘发送该月汇总统计，不发送交易方、订单号和日程标题。日记不发送给 AI。主动写入目标的个人信息会随目标发送。API Key 作为凭证发送到 https://api.deepseek.com，处理规则受该服务政策约束。

设备同步与联网

配对由用户扫码并确认后启用，电脑需运行并解锁。双方通过经过身份校验的 TLS 通道交换记录，不使用项目提供的云端中转。密钥和设置不交换，日记交换二次加密密文。电脑监听 TCP 3211、UDP 3212 供设备配对和发现，用户可在设置中撤销配对。

点击地点地图搜索时，地点文字会作为搜索词交给高德地图；应用不自动获取 GPS。打开学校教务入口时，由外部官方页面处理登录，应用不收集学校账号密码。

Android 权限

权限用途
网络用户开启的设备同步、AI 请求和外部链接
相机用户主动扫描配对二维码
生物识别用系统锁屏身份确认原生同步授权
读写系统日历用户授权后的课程和日程同步
设置闹钟用户设置的系统提醒

桌面课表组件仅在用户授权后缓存课程，使用 Android Keystore 加密；关闭展示或移除最后一个组件后清除缓存。错误摘要保存在本机，不自动上传。应用不包含用于广告或行为分析的跟踪服务。

删除与反馈

应用内可删除记录。为支持撤销误操作和同步，删除标记及最近的加密历史副本可能继续保留。Windows 卸载器保留 data/ 和 certs/，需要彻底移除时请先导出所需备份、退出程序，再手动删除这些目录。Android 清除应用数据或卸载会移除应用私有数据；用户导出的文件需另行删除。

普通问题可通过仓库 Issues 反馈。请勿在公开问题报告中发送个人记录或密钥；安全问题按仓库 SECURITY.md 说明处理。
