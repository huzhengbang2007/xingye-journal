# 星野记 3.0.0-rc · HOSHINO TEAM

本版为功能冻结的发布候选版本。Windows 安装包默认启动原生桌面窗口，Rust 引擎负责本地保险库加解密；Android 使用专用 HOSHINO TEAM release 签名。详细升级、验证和签名说明见 [RELEASE-3.0.0-rc.md](../../RELEASE-3.0.0-rc.md)。RC 标记不代表已经完成所有真实设备验收。

- 升级前从旧版本导出加密备份。Windows 安装升级保留 data 与 certs；卸载入口也保留个人数据。直接删除整个安装目录仍会删除这些文件。
- 新 Android release 签名不能覆盖旧调试签名。先导出旧应用备份，再进行迁移；不要先卸载旧版或清除数据。新正式包继续使用原 applicationId，不借更换包名掩盖签名差异。
- 手机同步需要本机锁屏身份确认；后台停用同步授权，回到前台后重新确认。没有设置系统锁屏时，离线记录仍可使用。
- 冲突重试仅在两端内容都未变时保留选择；恢复已删除的版本需要明确确认。批量删除、日记删除与恢复前都会保留加密历史副本。
- Windows 签名为 HOSHINO TEAM 自签名，不会自动导入受信任根或绕过 SmartScreen。第三方 Node 保留 OpenJS 官方签名。请通过可信渠道核对发布证书指纹。
- 双击 start.cmd 启动；原生窗口不兼容时可显式运行 start.cmd --browser。data/service-errors.log 提供本机服务诊断，日志按大小保留一代。
- 签名私钥保存在项目 .signing，口令由当前 Windows 用户的 DPAPI 保护。不要删除；跨机器备份应运行 scripts/export-signing-backup.ps1，使用自己保管的独立备份密码。

# 2.5.0 审核后修订（2026-10-24）

当前工作区包含审核修复，尚不是可正式发布的提交。同步现在校验保险库身份，省略记录不再代表删除；删除须显式提交，批量删除或删除日记须确认，服务端拒绝直接复活已有删除标记的记录。同步请求与手机响应统一限制为 16 MiB，未变化时只查询版本元数据。

2.4.1 手机端升级到本次配对协议时，需要先导出加密备份、升级手机与电脑，然后重新扫码配对。旧调试 APK 不作为正式发行包；新调试构建使用独立的 `.debug` 包名，不能覆盖原包，迁移前先导出本机备份。正式签名与原调试签名不同，不能直接覆盖升级。

Windows 构建只接受 `scripts/packaging/node-runtime.json` 指定的 nodejs.org 官方二进制及 SHA-256。正式构建要求所有源码已提交且工作区干净；`-AllowDirtyReview` 仅生成明确标记的审阅候选。包内哈希只能发现未同步修改清单的损坏，不能证明发布者身份；当前未提供 Windows 代码签名或独立可信发布渠道的签名证明。

启用设备配对后，TCP 3211 与 UDP 3212 监听全部网卡，应用检查私网及 CGNAT 来源；可达范围仍受防火墙影响，不配置公网端口转发。手机原生同步锁目前依赖页面成功解锁后的通知，并不独立验证主密码；不要把它描述成原生密码验证。

Windows 数据在安装目录的 `data/`。当前没有卸载器；手工删除安装目录会删除数据，应先导出备份。便携目录可能继承其他账户权限；`scripts/check-data-permissions.ps1` 仅检查，不更改权限。


# 星野记 Xingye Journal

一个在自己电脑上运行的个人日程、大学课表和生活账本应用。中文界面，适配电脑、手机和平板；本地数据与 DeepSeek 密钥以主密码加密保存。浏览器版无需 npm 安装；可选 Rust 原生预览见下。

## 2.5 扫码配对与自动同步

- 电脑解锁后点击顶部「连接设备」，手机或平板在星野记内扫码，再由电脑确认。以后设备打开并解锁、网络互通时自动同步，保留顶部的立即同步入口。
- 软件自动准备连接地址与加密身份，不再手填 IP、运行 HTTPS 脚本、安装系统证书或输入电脑主密码。设备凭证由 Android Keystore 保护，可以在电脑设置中重命名或撤销。
- 电脑身份与 IP 分离，地址变化后尝试局域网发现；发现受限时重新扫码即可。无冲突自动合并，有冲突再选择。电脑锁定或关闭时暂停同步，本机可继续离线编辑。
- 前台同步会避开正在编辑的表单和已解锁日记；后台持续同步不作承诺。没有云端服务，网络互访受限时统一使用自己的手机热点。见 [连接说明](../../CONNECTIONS.md)。
- 新协议由 Windows/Java TLS 实测、二维码解码和浏览器自动化验证；小米手机与平板的相机、网络、防火墙、升级与系统提醒仍需实机验收。本轮提供 2.5.0 候选测试包。

## 2.4.1 编辑保护与导入改进

- 日程、账本、设置的未保存编辑以密文保留在当前标签页，点击顶部「未保存编辑」恢复。密码和 API 密钥不进入草稿；刷新页面后需重新输入主密码，关闭标签页可能丢失草稿。
- 冲突时保留输入并展示当前保存值；被删除记录的草稿可明确选择恢复为新记录供核对，保存后才新增。
- XLSX 默认按工作簿顺序读取第一张表，也可填写表名选择；无效账单最多列出前 60 条解析行号及原因。电脑与手机共用 CSV、账单、ICS 和课表解析核心。
- 设置支持每日 AI 调用次数展示及 0–100 次上限，0 表示暂停；电脑和离线手机各自计数。自动任务展开对话后可导出明文 JSON。
- 设置新增诊断导出，只包含环境和记录数量，不含正文、账单明细、密码或密钥。
- Android 安装版本号递增为 6；正式签名和实机提醒验证仍沿用原有发布边界。

## 2.4 导航、每日课表和桌面组件

- 手机导航选中底板横向平移，页面横向过渡；701–1250px 平板采用独立固定胶囊侧栏，页面滚动不带动侧栏。
- 采用雾蓝、淡紫、月白渐变背景，保留深浅色；应用和 Android 图标改为现有女生原图头像。素材提示词见 [ART-DIRECTION-2.4.md](../../ART-DIRECTION-2.4.md)。
- 按最新反馈关闭手机缩放及字号调节。右下角 `Asia / Shanghai` 是原时区标识，现明确写为「北京时间 · UTC+8」，不是地理定位。
- 日程页新增每日课表、日期切换、上课中/已结束状态和地点地图搜索。地图搜索由用户主动点击；没有自动 GPS 定位或自动坐标解析。
- Android 可请求添加桌面每日课表小组件，支持大小调整。需主动同意展示课程，缓存由 Android Keystore 加密；关闭展示或移除最后一个组件后清除缓存。只包含课程，不包含日记/账单。课表变动后打开应用更新；后台定时刷新实际时机由系统决定，尚未在小米桌面实测。
- Windows 原生预览可打开独立每日课表小窗口；普通浏览器打开相同的精简课表入口。这不是微信小程序，也没有自动创建 Windows 桌面快捷方式。

- 课表可直接粘贴 Excel 表格、CSV/TSV；识别常见中英文列名、中文星期、单双周、全角钟点、Excel 数字日期/时间、星期矩阵及纵向合并课程。缺失周次或节次作息时直接在导入窗口补充，始终先预览再确认。
- 同步保留三方合并、过期预览检查及写入失败保护；2.5 已统一为扫码配对和前台自动同步。

## 2.1 独立手机版与流畅玻璃

- 合并更新推送、避免重复重建工作区、缓存日期索引和月度统计，并避免重复发送原生日历快照。

## 2.0 基础功能

- 星野蓝渐变、液态玻璃卡片、星轨与原创星猫；素材提示词与安装位置见 [ARTWORK-PROMPTS.md](../../ARTWORK-PROMPTS.md)。
- 多设备同时登录、实时更新推送、断线重连、设备命名与撤销；编辑日程、账单和设置有版本冲突保护。正在编辑时暂缓刷新，不覆盖输入内容。
- 电脑在应用内日历空白处右键、手机在日期空白处长按约 550 毫秒新建日程；滑动超过 10px 会取消长按，不影响页面滚动。表单、链接和已有事件保留正常操作。

- Android 独立端已编译出本地测试 APK，日历单向自动同步与标准系统闹钟桥接见 [android-companion/README.md](../../android-companion/README.md)。尚未在小米实机上验证。

**兼容旧数据**：保留内部 `data/daylight.vault` 和会话 Cookie 名称；更名不要求重建保险库。旧日程默认提前 10 分钟提醒。不要删除原有 data 文件夹。

## 马上使用

1. 双击项目里的 **start.cmd**，保持启动窗口开启。
2. 用浏览器打开 **http://127.0.0.1:3210**。
3. 首次设置至少 10 个字符的主密码。密码不能找回，请使用足够长且独有的密码并妥善保管。
4. 在「设置与安全」填写称呼、作息、预算及学期第一周的周一日期。
5. 在同一页面填入自己的 DeepSeek API Key 并保存。**不要把密钥写到源码里，也不需要发送到聊天里。**

需要 Node.js 22 或更新版本。启动脚本优先使用系统 Node，也兼容这台电脑上 Codex 自带的 Node 路径。若在另一台电脑运行且未安装 Node，请从 https://nodejs.org/ 安装。

也可以在项目目录执行：

```powershell
node server.mjs
```

本地服务已启动时，再运行一个副本会提示端口被占用；直接打开原来的地址即可。停止时在启动窗口按 Ctrl+C。换端口可设置 `PORT` 环境变量。

## 已实现的功能

- 生活概览：今日日程、本月已完成的学习时长、完成率、净支出与预算。
- 日程：新建、编辑、删除、标记完成，按月查看课程与个人计划。
- 课程表：官方教务入口，ICS / CSV / XLSX 文件导入，模板下载、周次与单双周展开、重复导入去重、时间冲突提示。
- 规划：DeepSeek 将目标拆为未来时段，先预览再确认；服务端再次检查日期、作息、时长和冲突。不填密钥也可使用本地空闲时段规划。
- 账本：微信与支付宝 CSV / XLSX 账单导入、预览、分类、平台内去重、收支筛选、搜索、分页、编辑与删除、CSV 导出。
- 月度复盘：收支、退款、分类、学习时长、完成率自动汇总；可单独授权生成 DeepSeek 建议；支持 Markdown 导出。
- 安全：保险库加密、密钥不回显、自动锁定、加密备份与恢复、恢复前副本、默认仅监听本机、设备配对通道强制加密与身份校验。

初次使用不插入假日程或假账单。`examples` 中的文件明确为示例，可用于练习导入，不代表用户真实记录。

## 大连理工大学课表

从应用的「大工教务处」进入官方页面 https://teach.dlut.edu.cn/index.htm ，在学校页面登录自己的账号。**应用不收集学校账号或密码，也不会绕过统一认证。**

目前没有经过用户账号验证的教务直连适配器；本版本提供文件导入，不宣称自动抓取或自动追踪调课。

### 推荐：ICS

如果学校系统或你已有的课程工具能导出 ICS，直接导入。支持：

- 单次有起止时间的事件。
- 北京时间、未带时区的本地时间（按北京时间解释）及 UTC。
- 每周重复、间隔周、多个星期、截止日期 / 次数和 EXDATE 排除日期。

不支持的全天事件、其他时区、特殊补课 RECURRENCE-ID、RDATE 和非每周重复规则会提示错误，不会猜测。

### CSV / XLSX

下载应用里的课表模板，或参考 `examples/课程表示例.csv`：

| 课程名称 | 日期 | 星期 | 开始时间 | 结束时间 | 周次 | 地点 |
| --- | --- | --- | --- | --- | --- | --- |
| 高等数学 | 留空 | 1 | 08:00 | 09:35 | 1-16 | 真实教室 |
| 大学英语 | 留空 | 3 | 10:05 | 11:40 | 1-16单周 | 真实教室 |

星期填 1–7；周次支持 `1-16`、`1,3,5`、`1-16单周`、`2-16双周`。先在设置里填写**真实学期第一周的周一**。有「日期」时按单次事件导入，星期和周次不生效。开始结束时间请根据本人校区和真实课表填写，示例时间不作为学校作息依据。

XLSX 默认按工作簿顺序读取第一张工作表，也可填写工作表名称选择。支持星期列矩阵与纵向合并单元格；表格缺少实际时间时在导入窗口填写节次作息，缺少周次时填写默认周次，不会猜测学校作息。跨星期横向合并、单格多组课程、截图/PDF 和旧版 XLS 暂不直接识别，旧 XLS 请另存为 XLSX。导入前核对预览，调课后删除旧课程并重新导入新课程。

## 微信与支付宝记账

1. 在支付应用里导出**用于个人对账**的账单明细，下载并解压邮件附件。
2. 星野记中选择对应平台，选择 CSV 或 XLSX 文件（最多 8 MB）。
3. 查看待导入、重复、跳过、无效记录数及明细预览，再确认导入。

常见入口（具体菜单可能随版本变化）：

- 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单。
- 支付宝：我的 → 账单 → 右上角菜单 → 开具交易流水 / 下载账单 → 用于个人对账。

支持 UTF-8 / GB18030 CSV、带前置说明的账单、引号内逗号和换行、常见 XLSX 共享字符串与内联字符串。文件在当前设备本地解析；手机独立端也在本机解析，配对后交换导入结果，不发送给 DeepSeek。原文件不会写入数据目录。XLSX 有解压大小与文件条目限制。

### 收支口径

- 金额以整数「分」保存，展示为元。
- 收入、支出、退款、转账 / 不计收支分开记录。
- 净支出 = 原支出 − 独立退款明细；月结余 = 收入 − 净支出。
- 仅有「已全额退款」「部分退款」状态而没有退款明细时，**不能从状态推断实际退款金额**。应用会提示核对；请根据真实退款手动补记。
- 不成功、关闭、撤销、未支付等交易跳过；识别不了的日期金额会计入无效数。
- 优先按平台 + 交易单号 / 交易订单号 + 收支方向去重；没有单号时用时间、交易方、金额、商品及方向生成指纹。同一订单同一方向的多次部分退款可能被合并，需人工检查并补录。
- 不跨平台猜测同一笔交易，也不自动核销信用卡还款与银行转账。避免把同一消费的多平台副本重复计入。
- 分类为本地关键词规则，可以在账单的「编辑」中修正。
- 导出 CSV 是**明文**，应用导出前会提醒；单元格会处理公式注入前缀。

## DeepSeek 与月度总结

接口固定为官方 `https://api.deepseek.com/chat/completions`，不允许输入任意代理地址。参考官方当前文档，默认模型为 `deepseek-flash`，可在设置中更改模型名称。

- AI 规划发送：本次目标、规划天数、单次时长、作息、当前北京时间，以及范围内现有日程的日期和起止时间；不发送已有日程标题和地点。
- AI 复盘发送：单个月份的收支总额、分类金额、日程总数、完成数、已完成学习分钟数等统计；不发送交易方、订单号和日程标题。
- 每次云端调用都需要页面上的明确确认，且会使用你的 DeepSeek 账户额度。API Key 只作为官方请求的 Authorization 凭证发送；不放进提示词。你主动写入目标的个人信息会随该目标发送。
- 不填密钥时，本地日程、账本、空闲时段规划、统计总结与备份仍可使用。
- AI 请求有超时和错误处理，结果需格式和时间校验。外部模型可能返回无效结果，应用会拒绝写入。
- AI 输出采用普通文本显示，不执行 HTML 或脚本。

**月度自动总结**：解锁时、查看数据时以及服务运行且保险库解锁时的每小时检查，会为上月和遗漏的历史月份生成本地汇总。关闭服务 / 锁定期间不会运行，下一次解锁会补生成。不需要电脑整月开机，不需要自动花费 AI 额度。AI 建议由你单独点击生成。记录变化后统计刷新，旧 AI 建议标记为过期。

## 天选电脑 + 小米手机 + 小米平板

电脑承担加密存储、解析账单和代理官方 AI 请求。没有本地大模型，无需消耗独显显存。界面按可用宽度自适应：电脑完整工作台，平板横屏双栏 / 图标侧栏，手机底部导航、触控按钮与安全区。使用北京时间，不依赖设备所在时区。

浏览器版含主屏幕应用清单，可添加到主屏幕或创建快捷方式。Android 独立安装包内置页面与本机加密数据，可离线编辑，配对后自动与电脑同步；系统日历和闹钟通过原生权限桥接。另有 Rust Windows 原生 EXE 预览，目前只用于本机；未接入 HyperOS 私有互联 API。电脑浏览器自身仍需电脑服务运行。

### 手机和平板连接

1. 电脑打开并解锁星野记，点击顶部「连接设备」。
2. 手机或平板打开并解锁星野记，点击「连接设备」扫描电脑二维码。
3. 电脑点击「允许配对」。之后打开并解锁时自动同步，无需电脑密码。

电脑需保持运行、解锁且网络可达。Windows 防火墙提示时允许专用网络访问；网络不通时让电脑连接自己的手机热点。电脑关闭时仍可离线编辑，之后补同步。记录冲突时需要选择版本；批量删除或删除日记需要确认。完整说明见 [CONNECTIONS.md](../../CONNECTIONS.md)。

## 数据、安全与备份

- `data/daylight.vault`：主数据，AES-256-GCM 随机 IV 认证加密，scrypt 从主密码派生密钥，独立随机盐。不存明文密码，不在源码或浏览器持久存储里放 API Key。浏览器只在本地存储是否开启此设备日历同步的偏好，不存手记密码、密钥或明文。
- 本地 HTTP 仅监听回环地址；非回环监听必须配置 TLS，否则服务拒绝启动。支持 PFX，或 `TLS_CERT_PATH` / `TLS_KEY_PATH` 的 PEM 证书。服务校验 Host、同源 Origin 和 CSRF token，Cookie 为 HttpOnly / SameSite=Strict，HTTPS 时增加 Secure。
- 30 分钟无认证请求自动锁定；页面无操作也会主动锁定。主密码错误有重试限制。手动锁定清除页面数据与服务端活动解密密钥；运行时内存不是独立硬件安全区。
- 不加载第三方脚本、字体或统计代码。页面受 CSP、frame-ancestors 和禁止缓存头保护。没有支付自动化、银行授权或读取其他应用私有数据的权限。
- 「导出加密备份」包含日程、账本、设置及加密密钥字段，保存为 `.vault`。请把备份放在另一块可靠存储上；它和主保险库一样需要当时的主密码。
- 「恢复备份」支持最多 64 MB，认证解密并校验记录后替换当前数据，先保留 `data/before-restore.vault`。恢复后的主密码沿用当前保险库密码；备份中保存的 API Key 和设置随记录恢复。旧 AI 复盘建议不恢复，统计重新生成。二次加密日记的密文完整恢复，仍需原来的独立日记密码解锁；恢复后的版本号更新，其他设备的旧编辑会被拒绝。恢复不会导入备份中的设备授权，当前配对设备及撤销状态保持不变。电脑按同步前、恢复前各保留最近 5 份历史副本，可从设置的「恢复历史副本」导出；手机保留最近 5 份。
- 主密码遗失没有后门。电脑被同账户恶意软件控制、保险库已解锁时的内存泄露、系统截图等不由文件加密解决。建议开启 Windows 设备磁盘加密、系统更新与锁屏。
- 本版本适合个人本地使用，未经独立安全审计。不要把这个单用户服务当作公网多租户产品部署。

### 自动任务与窗口界面

手机底栏采用悬浮玻璃 Dock，页面切换支持过渡动画，并尊重系统减少动态效果设置。2.4 已关闭移动端双指缩放和内置字号调节。Windows 启动时优先通过 Edge 应用模式打开独立窗口；未安装 Edge 时使用默认浏览器。

自动任务入口可设置首次执行时间（北京时间）和重复间隔（5 分钟至 30 天），支持暂停、恢复、立即执行、删除及查看完整对话。每个任务持续发送同一个原始请求，并携带该任务全部历史消息，回复加密存入保险库。这是软件内的 API 对话，不同步 DeepSeek 官网历史。自动任务不会自行修改日程。

执行需要服务运行、保险库解锁和已配置 API 密钥。锁定及关机时停止执行，恢复后至多补执行一次；失败在下一间隔重试，不连续补发。轮询精度为约 15 秒，其他 AI 请求运行时顺延。任务历史达到容量上限后显示错误，需要新建任务；手机独立离线模式暂不支持自动任务。API 调用会产生费用，创建前需确认发送范围。

开发环境安装：`npm ci`，然后运行 `npm test`、`npm run check`、`npm run format:check`。浏览器检查先运行 `npx playwright-core install chromium`，再运行 `npm run test:browser`、`npm run test:offline`。可选性能检查为 `node scripts/ui-performance-check.mjs`。需要指定系统浏览器时使用 `CHROME_PATH`；`PLAYWRIGHT_MODULE` 仅供已有工具环境覆盖。

AI 每日调用上限默认 100 次，可在设置中调为 0–100 次（按北京时间，服务器端跨重启保留计数），包含失败请求；这不是人民币预算或实际账单。生活预算字段不控制 API 费用。锁定后未保存的手记尝试保留为当前标签页的加密草稿，重解锁后询问恢复；关闭标签页仍可能丢失草稿，请及时保存。日程、账本和设置支持当前标签页内的加密草稿恢复，入口为「未保存编辑」。不保存密码和 API 密钥；关闭标签页可能丢失草稿，刷新页面需重新输入主密码。

Android 发布默认要求四个环境变量：`XINGYE_KEYSTORE`、`XINGYE_STORE_PASSWORD`、`XINGYE_KEY_ALIAS`、`XINGYE_KEY_PASSWORD`；正式签名材料不得提交 Git。`build-android.ps1 -Debug` 仅用于本人侧载测试，沿用 `.signing/debug.keystore`；请将此文件备份到你控制的安全位置。丢失原签名无法覆盖升级，卸载会删除手机本机数据，升级前先导出加密备份。正式签名与已有调试签名不同，不能直接覆盖旧测试版。DeepSeek 等普通网络请求只信任系统 CA；配对同步仅使用扫码绑定的电脑身份，测试包同样不依赖用户安装的证书。

设备同步的电脑私钥保存在 `data/device-identity/identity.pfx`，随机口令由当前 Windows 用户的 DPAPI 保护，目录仅允许当前用户访问。手机只持有电脑的公开指纹和本机设备凭证，凭证通过 Android Keystore 加密保存。不要手动删除身份目录；更换 Windows 用户或电脑后需重新配对。旧 HTTPS 脚本仅留在开发源码兼容检查中，不再进入新安装包；旧用户证书与文件不自动删除。
