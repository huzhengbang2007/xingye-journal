# Windows 安装器参数与返回码

适用范围：星野记 3.0.0-rc 的 **installer revision 2**，文件名以 `-setup-r2.exe` 结尾。旧 `-setup.exe` 不支持本文的静默安装约定，不能使用相同 URL 覆盖旧文件。

## Microsoft Store 包信息

- 体系结构：x64。
- 应用类型：EXE。
- 语言：简体中文（zh-CN）。
- 安装程序参数：`/quiet /norestart`。
- 不勾选“安装程序在无提示模式下运行，但不需要切换”。
- 返回码说明网址：<https://huzhengbang2007.github.io/xingye-journal/installer.html>。
- 安装包仍使用 HOSHINO TEAM 自签名，**不代表已经满足 Microsoft Store EXE 的可信 CA 签名要求**。也不能把 EXE 下载链接填到 MSIX 上传入口。

## 使用方式

双击安装器打开中文安装向导。取消向导返回 1602；安装成功后关闭返回 0。安装中的向导不能直接关闭以中断文件更新；若安装失败，退出时返回该次失败码。

无人值守安装：`xingyeji-3.0.0-rc-windows-x64-setup-r2.exe /quiet /norestart`。

静默模式不显示安装向导、对话框或命令窗口，不会在安装后自动启动应用，不会请求提权或重启电脑。默认安装到当前用户的 `%LOCALAPPDATA%\XingyeJournal`，默认创建桌面和开始菜单快捷方式。更新保留已有 `data/` 与 `certs/`；进程退出前完成安装或失败回滚，不把启动后台工作进程误判为安装完成。

可选参数：

| 参数 | 含义 |
| --- | --- |
| `/quiet` 或 `/S` | 静默安装；商店建议固定使用 `/quiet` |
| `/norestart` | 不重启；本安装器本来就不会重启系统 |
| `/dir="完整路径"` | 指定安装文件夹，不允许相对路径或磁盘根目录 |
| `/log="完整路径"` | 将安装日志追加到指定文件；默认保存在 `%LOCALAPPDATA%\Hoshino\InstallerLogs` |
| `/nodesktop` | 不创建桌面快捷方式 |
| `/nostartmenu` | 不创建开始菜单快捷方式 |

无法识别的参数会失败，而不是被悄悄忽略。安装器不联网下载依赖，不改变系统证书信任根，不关闭安全校验。完整路径可含空格、中文和单引号。

## 返回码

以下是安装器自行实现的十进制代码；即使数值与部分 Windows/MSI 代码相同，也只以本安装器的实现为准。

| 代码 | 含义 | 商店对应项 |
| --- | --- | --- |
| 0 | 安装成功，包括成功覆盖升级 | 安装成功 |
| 1602 | 用户在手动安装向导中取消或关闭 | 用户已取消安装 |
| 1618 | 当前用户已有另一个星野记安装器或安装工作进程 | 安装已在进行 |
| 112 | 空间检查不足，或系统报告磁盘已满 | 磁盘空间已满 |
| 13 | 内嵌载荷损坏、发布签名/文件哈希不匹配或载荷结构不符合要求 | 其他安装失败；不要填“安全策略拒绝包” |
| 5 | 当前用户无权读写安装所需文件 | 其他安装失败 |
| 87 | 未知参数、无效安装路径 | 其他安装失败 |
| 170 | 星野记的程序或随包运行时仍在目标目录运行，不能覆盖升级 | 其他安装失败 |
| 1633 | 不是 64 位 Windows | 其他安装失败 |
| 1603 | 未归入以上情况的安装失败 | 其他安装失败 |

“应用程序已存在”留空：已安装时执行升级，不以独立错误码拒绝。“需要重新启动”留空：本安装器不请求重启。“网络故障”留空：安装过程离线，不定义联网故障码。“已在安装期间拒绝包”留空：没有把 Windows 安全策略阻止启动映射为安装器自己的返回码。

失败时保留诊断日志；若回滚无法全部完成，会报告保留的临时备份路径。不要在公开反馈中发送个人保险库、日记、账单或密钥。

## 签名与 MSIX

本次改造解决静默安装和返回码，不会把自签名证书变成可信 CA 证书。EXE 路线仍需合规的发行签名服务；MSIX 路线可以由商店重新签名，但必须使用后台的 Package/Identity/Name、Package/Identity/Publisher 和 PublisherDisplayName，并单独处理只读安装目录、用户数据位置与升级迁移，不应直接把现有文件压缩改后缀。

参考：[Microsoft EXE/MSI 要求](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/app-package-requirements)、[Microsoft MSIX 签名说明](https://learn.microsoft.com/en-us/windows/msix/package/sign-msix-package-guide)。
